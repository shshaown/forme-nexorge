# FORME One
Original minimalist chair website concept by NEXORGE. Seven complete pages, a procedural Three.js chair with raycast part selection, keyboard/drag rotation, recline and height controls, desk setup, three concept finishes and a browser-only downloadable enquiry brief.

Run: `python3 -m http.server 8086` from this folder.

Product is fictional. Ranges, room mockups and finishes are illustrative, not manufacturing specifications. No checkout or real enquiry transmission.

Assets: original AI-generated studio.png and evening.png. Studio prompt: premium ivory upholstered graphite-frame ergonomic chair in a minimalist walnut gaming studio with warm sunlight. Evening prompt: same chair, adult woman gaming with controller, cinematic blue and amber evening lighting. Original geometry and interface code. Third-party Three.js and Manrope licenses included in assets.
